# Docs index

Read these in order if you are new, or if you just pulled.

1. [`TEAM_BRIEF.md`](TEAM_BRIEF.md) — two minutes. Status, setup, who owns which track.
2. [`TEAM_HANDOFF.md`](TEAM_HANDOFF.md) — what is decided, what exists, and how to resume.
3. [`../TerraSense.md`](../TerraSense.md) — the product. If a feature is not in its hackathon scope, do not build it.
4. [`../implementation-steps.md`](../implementation-steps.md) — steps 1–25 from this repo to the demo.
5. [`UX.md`](UX.md) — before you add a screen or a control.
6. [`CODE_REFERENCE.md`](CODE_REFERENCE.md) — when you need a file. Update it in the same change that adds or renames code.

The root [`README.md`](../../README.md) is the one-line pitch. This folder is the working set.
