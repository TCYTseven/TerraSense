# TerraSense frontend

Next.js App Router app for TerraSense: the 3D globe, the mountain view, and the hiker card.

```bash
npm install
npm run dev          # http://localhost:3000
npm run lint
npm run typecheck    # next typegen, then tsc --noEmit
npm run build
```

Environment variables live in the repo root `.env`. See [`../.env.example`](../.env.example).

Agents and contributors: read [`AGENTS.md`](AGENTS.md) and [`../context/docs/UX.md`](../context/docs/UX.md) first.
